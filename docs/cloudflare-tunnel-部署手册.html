一、原理：流量是怎么走到你电脑上的

用户浏览器→ Cloudflare 全球节点
audit-companion.xyz→ Cloudflare Tunnel 加密隧道→ 本机 cloudflared 连接器→ 本机应用
localhost:8000

关键点：cloudflared 只从内网向外发起连接（outbound-only），你的电脑不需要公网 IP、不需要开端口、不需要备案。HTTPS 证书由 Cloudflare 自动签发。

三、全新换一台电脑 / 换一个域名时的完整流程

0

前提清单

  • 一个 Cloudflare 账号（免费版即可）
  • 一个域名（.xyz/.top 之类很便宜；国内注册商买需实名认证）
  • 本机能跑你的应用（本项目：Python + uvicorn，端口 8000）
  • 能上网（下载 cloudflared 时如 GitHub 超时，直接用 winget install Cloudflare.cloudflared）
1

域名侧：实名认证 + 把 DNS 交给 Cloudflare

  1. 在注册商（阿里云：控制台 → 域名 → 点进你的域名）完成实名认证。没通过实名之前域名处于 client hold 状态，全网无法解析，后面全部白搭。
  2. 注册/登录 dash.cloudflare.com → Add a domain → Connect a domain → 输入域名 → 选 Free 计划 → 扫描记录页直接 Continue（新域名本来就没记录）。
  3. Cloudflare 会分配两条 NS，例如 gabe.ns.cloudflare.com / joyce.ns.cloudflare.com（每账号固定）。
  4. 回到注册商，找到「DNS 修改 / DNS 服务器设置」，删掉默认的 DNS，替换成 Cloudflare 的两条，保存。
  5. 等注册局状态里的 clientHold 消失、NS 生效（几分钟到几小时），Cloudflare 域名页变绿显示 "Your domain is now protected by Cloudflare" 即激活成功。
检验 NS 是否真的生效：不要只看注册商后台，去查注册局数据。最稳的办法是在浏览器控制台里访问 RDAP 接口，例如 https://rdap.centralnic.com/xyz/domain/你的域名，看返回 JSON 的 nameservers 和 status 字段。
2

Zero Trust：激活（一次性）

  1. Cloudflare 控制台左侧进 Zero Trust（新版叫 Cloudflare One），首次会要求选套餐，选 Zero Trust Free（$0/月，50 席位）。
  2. 结账页虽然金额是 $0，但必须绑定支付方式做验证（银联卡 / PayPal / Apple Pay / Google Pay 任一）。填卡号、有效期（月/年）、安全码 = 卡背面 3 位 CVC（不是取款密码）、账单地址，勾选两个同意框，点 Activate。
  3. 激活后团队名（team name）会自动分配，记下来即可。
3

创建隧道

  1. Zero Trust 控制台 → Networks → Tunnels & Mesh（旧路径 /networks/tunnels 已 404）。
  2. Add a tunnel → 选 Cloudflared → 起个名字（如 audit-companion）→ Save tunnel。
  3. 此时页面给你一条安装命令：cloudflared.exe service install eyJhIjoi…，其中 eyJ 开头的一长串就是 Token。点 Copy to clipboard 保存好，下一步要用。
4

绑定公网路由（Published application route）

  1. 继续向导或事后进隧道详情 → Published application routes → Add a published application route。
  2. Subdomain 留空（用根域名），Domain 下拉选你的域名（域名没激活前这里是空的，属正常）。
  3. Service：Type 选 HTTP，URL 填 localhost:8000（注意不带 http:// 前缀，前缀由 Type 表示）。
  4. Save。DNS 的 CNAME 记录会自动创建，无需手动加。
5

本机跑起来（两个进程）

① 先启动应用

cd "D:\deepseek harness document\老师那边的智能体9_2\server"
./.venv/Scripts/python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000

自检：curl http://127.0.0.1:8000/health，返回 JSON 即正常。

② 启动 cloudflared 连接器

& "C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel --no-autoupdate run --token 把Token粘贴到这里

看到 Registered tunnel connection 字样即连接成功。PowerShell 里执行带引号路径的命令要在前面加 &；CMD 里直接写路径即可。

6

验证

  • 浏览器打开 https://你的域名/health，能返回应用 JSON。
  • Cloudflare 隧道列表里状态为 Healthy。
  • 隧道详情 Connectors 表里出现你的机器（windows_amd64，Connected）。

四、日常恢复：电脑重启后要做什么

隧道配置、路由、域名这些都存在云端，重启电脑后只需要把两个进程重新跑起来：

REM 1. 启动应用 (窗口 A)
cd /d "D:\deepseek harness document\老师那边的智能体9_2\server"
.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000

REM 2. 启动连接器 (窗口 B, Token 从备份文件里取)
"C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel --no-autoupdate run --token 你的Token

五、想开机自启、无人值守：装成 Windows 服务

用管理员身份打开命令提示符（CMD），执行：

cloudflared service install 你的Token

之后 cloudflared 会随系统自动启动、断线自动重连，不再需要手动开窗口。卸载服务用 cloudflared service uninstall。

服务只解决 cloudflared 这一环；应用本身（uvicorn）仍是手动跑的。想连应用也常驻，可以用 NSSM 把 uvicorn 注册为服务，或用项目里现成的 docker-compose.sim.yml 起容器。

六、踩坑实录（照做能省两小时）

症状 / 坑原因与解法
域名全网打不开，DNS 查询返回 NXDOMAIN注册商侧 clientHold 状态（实名认证未通过）会暂停解析。去注册商过实名，等状态消失。光改 NS 没用。
隧道向导里 Domain 下拉框是空的（No valid options）域名还没在 Cloudflare 激活。等 zone Active 后下拉里才会出现。
Cloudflare 一直显示 "Waiting for nameserver propagation"注册局还没发布你的 NS 或仍有 hold。去 RDAP 查真实状态，别干等控制台。
GitHub 下载 cloudflared 超时，gh-proxy 等镜像也失败直接 winget install Cloudflare.cloudflared，走微软源，实测秒装。
保存路由时报 "url is required"，明明已经填了自动化/输入法填的值没进表单状态。手动点进输入框，逐字敲一遍再保存。
本机 nslookup / 直连 DNS 查询被拦截超时网络环境限制。改用浏览器上下文 fetch DoH（https://cloudflare-dns.com/dns-query?name=域名&type=NS，header 带 accept: application/dns-json）或 RDAP。
隧道 Healthy 但公网 502本机应用没起，或端口不是 8000。先 curl 127.0.0.1:8000/health 验应用，再看 cloudflared 日志。
本地是 memory 存储环境当前以 environment: development 运行，应用重启后演示数据会重置；正式数据要接持久化配置。

七、常用排查命令速查

REM 应用是否活着
curl http://127.0.0.1:8000/health

REM cloudflared 连接是否正常(看有没有 Registered / Lost connection)
tasklist | findstr cloudflared

REM 查域名 NS 是否已切到 Cloudflare(浏览器地址栏直接打开)
REM https://rdap.centralnic.com/xyz/domain/audit-companion.xyz

REM 重载连接器
cloudflared tunnel run --token 你的Token

REM 装卸系统服务(管理员 CMD)
cloudflared service install 你的Token
cloudflared service uninstall
